Ganymede · design language

Colour that means something.

This product's claim is epistemic honesty about numbers. So the palette is semantic, not decorative: every colour family carries exactly one decision meaning, and every figure on the site wears the kind of evidence standing behind it. A visitor absorbs the thesis from the system before reading a sentence.

01The mark

A moon in phase, where the day–night boundary is not a clean arc but a bent trajectory. Ganymede is the moon; the wobble is the thing the Risk Lens is built to see. It reduces to a filled disc with a wave through it, which is what survives 16 px.

02Four families, four jobs

Ramps are generated in OKLCH by scripts/gen_palette.py so the steps are perceptually even, then contrast-verified against fourteen named pairs on every build. Nothing in the site's CSS references a raw step — only the semantic names below — which is what keeps the meanings enforceable rather than aspirational.

The rule that does the work

A probability is never coloured red, amber and green. Three colours over a scalar invent category boundaries the model never produced, and an agent reads those boundaries as the system's opinion. Probabilities get the Ember ramp, where lightness alone encodes magnitude. Green and red are spent only on realised outcomes — a promise kept, a promise broken.

Ember means we predict. Green means it occurred. That distinction is the product's epistemology, in colour.

p(worsen) — drag it

Lightness is monotonic across all eleven stops, so the ramp keeps encoding magnitude in greyscale and under deuteranopia. Verified on generation — if a stop ever breaks monotonicity the build fails.

03Provenance badges

The component that makes the site self-explaining. Every number carries the kind of evidence behind it, mapped onto distinctions the codebase already enforces — invariant I1, the playbook's is_provisional flag, and the phase gates. Shape differs as well as colour, so the distinction survives greyscale.

BadgeMeansExample
measured Observed directly from real data 479 ms median inter-turn gap
backtested Real data, held-out split L1 AUC 0.62

seeded Practice-derived, zero outcome support every playbook strategy
pending Needs a pilot; deliberately not estimated override rate

A figure rendered without a badge is a bug, not a style choice. The site's data files carry the provenance field alongside the value so a chart cannot draw one without the other.

Glossary terms

Any domain word gets a definition where it is used, from one JSON file shared with the glossary page — so the tooltip and the page can never disagree. Hover or focus: self-cure, promise to pay, uplift, calibration.
