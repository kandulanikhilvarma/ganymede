# Design spec, 2026-09-29

BRAND_LOCK is soft. The existing system stays: ice for the system's own signal, ember for the magnitude of a prediction, kept and broken only for realised outcomes, Fraunces for argument, Geist and Geist Mono for readout. This run extends it where the audit found gaps. It does not restyle it.

All colour values are generated by `scripts/gen_palette.py`. Nobody edits `site/assets/tokens.css` by hand.

## References

Mobbin needs a paid plan in this session (toolbox gap), so the references are public design systems and data sites. One pattern taken from each, and what was left alone.

| Reference | Pattern taken | Ignored |
|---|---|---|
| Our World in Data, chart pages | A "Table" view of the exact data behind each chart | Their tabbed chart chrome; a `<details>` disclosure fits this site's quieter layout |
| GOV.UK Design System, error message | Inline error text tied to the field with `aria-describedby`, plus `aria-invalid` | The red left border on the whole form group |
| GitHub keyboard shortcuts setting | A switch that turns single-key shortcuts off (WCAG 2.1.4) | A settings page; the switch sits in the desk's own help dialog |
| WCAG Understanding 1.4.13 | Hover content stays while the pointer moves onto it | Nothing |
| FT Visual Vocabulary | A magnitude ramp keeps one hue family and changes lightness | Nothing, the palette already did this |
| Stripe docs, code-sample state in URL | Put the view state in the address (`?cap=5`) so it can be linked | Tabs and language switchers |

No brand, logo, or protected layout was copied.

New gate: `SEMANTIC_GATES` checks the pairs pages use (faint on ground and surface, muted on surface-2, signal on signal-quiet, field on ground and surface) in both themes. Every `--on-risk-N` is gated at 4.5:1. Total gates: 14 ramp + 12 semantic + 11 on-risk = 37.

Unchanged: type scale (`--fs--2` to `--fs-8`, 1.2 ratio, 17 px base), 4 pt space scale (`--s-1` 4 px to `--s-12` 128 px), radius (`--r-1` 4 px to `--r-4` 16 px), shadows.

## Motion

| Property | Duration | Easing | Trigger | Reduced motion |
|---|---|---|---|---|
| Button background, border | `--dur-fast` 120 ms | `--ease-out` | hover | the global rule in `base.css` stops transitions |
| Press offset (1 px) | none | none | `:active` | no transition, so nothing to reduce |
| Walkthrough step colour and border | `--dur` 220 ms | `--ease-out` | scroll into view | global rule |
| Desk risk counter | rAF count-up | eased by 0.18 per frame | account change | set directly when `prefers-reduced-motion: reduce` (fixed) |
| Tooltip hide | 200 ms delay | none | pointer leaves term | a delay, not an animation |

Rejected motion: a count-up on the evidence tables and animated table reveal. Both would slow reading of numbers without adding meaning.

## Open design decisions (parked)

- Dark stays the default and `prefers-color-scheme` is ignored (V-06).
- Font preload weight (96.7 KB on every page) and the un-preloaded Fraunces italic on the h1 (F-06).
- Whether `design.html` stays unlinked (U-03).
- Which real account the home-page walkthrough should follow (its 0.81 and 0.18 are illustrative).
